# The port's own pictures

These are the only pictures in the repository. None of them come from Uncanny Cat Golf; they are built into the 3dsx/cia (`romfs:/port/`) so the intro and the "Oops" screen work even before the game's files are on the SD card.

| File | What it is | Where it comes from | Licence |
|---|---|---|---|
| `nickbin-logo.jpg` | NickBin's logo, the flag on the intro's putting green | made by NickBin | NickBin's own |
| `upset-cat.jpg` | the hissing cat on the "Oops" screen | ["Angry cat by Juliet van Ree"](https://commons.wikimedia.org/wiki/File:Angry_cat_by_Juliet_van_Ree.jpg) by Jvanree, Wikimedia Commons (500 px copy) | [CC0](https://creativecommons.org/publicdomain/zero/1.0/) |

Everything else on those screens (the scorecard, the green, the Oops lettering, the sad trombone) is drawn or made by `tools/convert/credits.py`.
